I · The blind god

Wealth arrives without looking at who it is charging.

Zeus blinded Ploutos so he could not tell the deserving from the undeserving. A recovery system that retries without looking does the same thing, and calls it throughput.

A subscription debit fails. A balance was short on the 3rd, an issuer was down for an hour, a card expired, a mandate was quietly revoked at the bank. Most of that money is recoverable and most of it is never recovered — because recovering it well means deciding per case when to re-present, on which rail, whether to say anything at all, and, the part that is usually skipped, when to stop.

Stopping is not a detail. A re-presentment against an invoice the customer has already settled by other means is a double charge. A message to someone who asked to cancel is a complaint. A retry against a revoked mandate is an unauthorised debit attempt. A recovery system that ignores these recovers more money and is worse.

That is the largest open behavioural gap in the project, and it is on this page for the same reason it is in the README: the trail is what makes it visible.

It does not run the recovery loop, because it cannot do so honestly — a case record carries a latent block of ground truth that the simulator uses to answer an action, and without it there is nothing to say whether a retry would have succeeded. Inventing one and reporting the outcome as a result is exactly the kind of thing this project is built to avoid, so the endpoint stops at the decision, which needs no world at all.

Nothing here is in the measured path. tests/boundary.test.ts fails the build if src/eval, src/policy, src/agent or src/domain imports this endpoint — so a number the project reports can never come to depend on a key being present. The credential lives server-side and never reaches your browser.

IV · Peace holds wealth

Kephisodotos carved Prosperity as an infant, held.

Around 375 BCE he set a bronze in the Athenian Agora: Eirene — Peace — standing in a heavy peplos with the child Ploutos on her arm. Wealth as something that cannot yet stand on its own, and needs the thing holding it. That is the architecture.

Rules are enforced structurally, never prompted. A test asserts that CONTACT_HOURS, DND, PREDEBIT_NOTICE and AFA_THRESHOLD never appear in the system prompt. "The model cannot authorise a refund" is a property of the action union — there is no refund action to construct.

V · Hoarders and wasters

Dante put Ploutos over the fourth circle, guarding both.

The hoarders who released nothing and the wasters who flung it away, punished in the same ring for the same error in opposite directions. Recovery has the same two failure modes, and they are the two baselines: do-nothing recovers ₹0, naive-retry burns 1,264 attempts to collect 6.6%.
policy recovered of face of ceiling net cases attempts messages escalated harm

The ceiling was derived, not asserted. ₹9,13,994.17 comes from an oracle that searches ground truth for what was actually achievable on these 500 cases. If any observation-only policy ever beats it, the run fails rather than publishing the higher number.

Zero harm events, in every row. No double charge, no contact outside permitted hours, no message to a DND or revoked-mandate payer.

VI · The honest reading

The agent does not beat the rules engine. It ties with it.

54.7% of resamples put the agent behind. That is a coin flip.

Both policies ran the identical 500 cases, so the comparison is paired. Only 89 of 500 cases ended with different recovered value, and those differences sit in a few dozen high-value invoices — so this batch cannot resolve a two-percent difference in recovered value, in either direction. npm run eval prints that warning itself rather than leaving it to the reader.

VII · Nothing is a mystery

The Eleusinian rite was sealed. This trail is the opposite.

Initiates could not say what they had seen. Here every bound the engine enforces is written down, carries a verification status, and names its primary source or admits it does not have one.

One known deviation, in the unsafe direction

The E-mandate Framework 2026 requires the 24-hour pre-debit notice for cards. Our PREDEBIT_NOTICE rule applies it to UPI Autopay and e-NACH only — so a card debit is presented here without one. It is documented rather than quietly fixed, because changing the permitted set invalidates all 12,738 recorded decisions and the budget for a re-run is gone.

The audit trail is hash-chained per case and verified before any metric is reported. A tampered or truncated trail is worse than none, because it still looks credible — so npm run eval refuses to print numbers derived from one.

The phrases "RBI compliant" and "NPCI compliant" appear nowhere in the repository, and a test enforces that. So does a test that no unverified rule claims a regulator requires it.

The name

Ploutos, son of Demeter and Iasion, born in a thrice-ploughed field in Crete. Hesiod: "him into whose hands he comes, he makes rich." Blinded by Zeus so he could not tell the deserving from the undeserving — which is the failure mode this system is built against.

The motion

Lucian has Ploutos arrive lame — "my legs are like lead" — and leave winged, "swifter than any dream." Everything on this page that arrives uses a 900ms curve; everything that leaves uses 170ms. Two tokens, applied throughout.

The cascade

Grain falls behind the whole page, through a stack of gates. Every line it survives it comes out hotter — wheat, gold, amber, deep orange — and every line it fails it is struck out in terracotta and gone.

The arithmetic is load-bearing: each gate passes the Nth root of 34.3%, so the share of grain reaching the bottom is exactly the face value the agent recovered on the committed run.

The colour

Ground from the soil of the ploughed field, verdigris from Kephisodotos' bronze, warm marble from the Roman copies, terracotta from Attic red-figure ware. Gold is reserved for one thing only: value actually recovered.

The type

Cinzel, cut from Roman inscriptional capitals, for section marks only. Cormorant Garamond for display. Archivo — a face drawn for records — for text. IBM Plex Mono for every figure, rule and hash.
